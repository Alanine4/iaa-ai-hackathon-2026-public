Every change to data handling, code behaviour or modelling assumptions is recorded here.
Each entry: what changed, why, evidence, and where it lives in code (`file:function`).
Raw files in `data/` are never edited; all corrections are applied in code at load time.

| C027 | 2026-10-22 | model / validation | Early-stopping leakage fix. `fit(..., valid="inner")` carves a seeded random 10% of the training rows (numpy `default_rng(SEED)`, exactly `n // 10` rows) as the early-stopping set, trains on the other 90% and sets `best_iteration` from it; the scored fold is never seen. Implemented once in `Balanced.fit`; GLM/GAM (`early_stops = False`) accept `"inner"` and ignore it (train on all rows, as with `valid=None`). Tests (`tests/test_models.py`): lgbm/xgb/cat with `valid="inner"` give integer `best_iteration` in [1, 150], positive predictions and exact training balance; glm/gam give identical predictions with `"inner"` and `None`; two inner fits give identical predictions (6 new tests failed with ValueError before the change, all 25 in the file pass after).
